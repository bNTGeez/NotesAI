# NotesAI

A modern AI-powered note-taking application that automatically generates detailed, structured notes from YouTube videos. Built with Next.js, Flask, and OpenAI's GPT-3.5 Turbo.

## Features

🎥 **YouTube Integration**

- Extract transcripts from any YouTube video
- Support for various YouTube URL formats (standard, shorts, embeds)
- Real-time transcript processing
- Automatic caption detection

📝 **Smart Note Generation**

- AI-powered note creation using GPT-3.5 Turbo
- Structured formatting with clear sections
- Bullet points and hierarchical organization
- Key concepts and main ideas extraction

⚡ **Real-time Processing**

- Instant note generation
- Streaming responses for live updates
- Progress indication during generation
- Error handling and retry logic

🎯 **Key Features**

- Clean, modern UI with Material-UI
- Responsive design for all devices
- Dark/light mode support
- Markdown rendering for formatted notes
- Error handling with user-friendly messages

## Tech Stack

### Frontend

- Next.js 14
- TypeScript
- Material-UI
- Tailwind CSS
- React Markdown

### Backend

- Flask (Python)
- YouTube Transcript API
- OpenAI GPT-4 Turbo
- CORS support
- Gunicorn server
